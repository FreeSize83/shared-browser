# Общий браузер с входом через GitHub

Один браузер (Firefox) работает на сервере, все пользователи видят и управляют им вместе — рассинхрона нет, потому что экран один. Видео и звук идут по WebRTC.

## Запуск

1. Нужен VPS с Docker (рекомендуется 4+ vCPU, 4+ ГБ RAM) и доменом.
2. Откройте порты: 80/tcp, 443/tcp, 52000/tcp и 52000/udp.
3. Создайте GitHub OAuth App: https://github.com/settings/developers
   - Homepage URL: `https://ВАШ_ДОМЕН`
   - Callback URL: `https://ВАШ_ДОМЕН/oauth2/callback`
4. `cp .env.example .env` и заполните значения.
5. `docker compose up -d`
6. Откройте `https://ВАШ_ДОМЕН` и войдите через GitHub.

## Что сделано для удобства

- Один клик «Войти через GitHub», потом сразу экран браузера под вашим ником (без второй формы входа), сессия живёт 30 дней.
- Firefox настроен через [policies.json](policies.json): uBlock Origin, автовоспроизведение видео, без запросов уведомлений/камеры/геолокации, без окон первого запуска.
- Если UDP заблокирован (офис, мобильная сеть), WebRTC уходит на TCP-порт 52000.

## Если что-то не работает

- Нет картинки/видео: проверьте, что `PUBLIC_IP` в `.env` верный и порт 52000 открыт (tcp и udp).
- Авто-вход не сработал: Neko другой версии может не принимать `?usr=&pwd=`; тогда пользователю достаточно ввести ник на форме.
- uBlock не появился: путь к `policies.json` в образе мог измениться, проверьте `docker compose exec neko ls /usr/lib/firefox*/distribution`.

## Важно знать

- Все вошедшие пользователи делят один браузер и одну сессию: любой может открыть сайты, и все это видят. Не входите в личные аккаунты внутри этого браузера.
- В `noauth`-режиме Neko все имеют равные права; управление переходит тому, кто кликнул первым (implicit hosting).
- Нагрузка на сервер не растёт с числом зрителей так сильно, как у отдельных браузеров, но каждому зрителю идёт свой WebRTC-поток. Для сотен зрителей понадобится мощный канал.
- Фильмы с DRM (Netflix и т.п., Widevine) в такой схеме могут не работать.
- Входом в сам Neko защищён только веб-интерфейс; порт 52000 принимает WebRTC-трафик напрямую.
